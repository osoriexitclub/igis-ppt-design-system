### 4.2 작성 지침 (`IGIS_Deck_Authoring_Guide_v2.md`)

- **기반:** 제공된 `IGIS_Deck_Authoring_Guide.md`. v1에는 별도 작성 지침이 없었고, `slide-types.md`와 `README.md`에 흩어진 작성 규칙을 통합했습니다.
- **주요 변경:**
  - §2: 기능명 대신 실제 ID 체계(레이아웃·유형·BC·BP·하드 룰)와 정의 위치를 표로 연결.
  - §4: 메시지 유형 (구 `slide-types.md`에서 이동, "시나리오" 행 추가).
  - §5: 사실·해석·가정·전망·권고·한계 구분과 장표 표기(BC-04 태그, `(E)`·`(F)`) 신설.
  - §6: 10개 내용 유형 A~J. 각 유형에 독자 질문, 제목 결론, 데이터·근거, 실제 참조 ID, 선택 이유·적용 조건, 피할 표현, 검수, 참고 관찰 범위를 둠.
  - §7: 제목·설명문 규칙 + 표·차트·설명 역할 분담 표 (구 README 문안 원칙 포함).
  - §8: 수치 검수 (원 가이드 §6 + 증감 표현). 표시 형식은 DS를 참조만 함.
  - §11: 빠른 선택표 (구 `slide-types.md`에서 이동, v2 유형 추가).
- **중복 점검:** 작성 지침에서 글자 크기·색·선 굵기 같은 시각 규칙을 모두 제거하고 DS 참조로 바꿨습니다 (자동 검사 결과는 7절).

### 7.3 실제로 검증하지 않은 범위

- **PowerPoint 실기 렌더링:** 신규 본문 구성요소(BC)의 PPT 구현 샘플은 만들지 않았습니다. 견본은 HTML뿐이고, PowerPoint에서 같은 결과가 나는지는 확인하지 않았습니다. 기존 템플릿은 v1과 동일합니다.
- **Claude Design 업로드:** 실제 업로드와 Design System 탭 렌더링은 하지 않았습니다.
- **실제 프린터 출력:** 흑백 확인은 화면 회색조 변환입니다. 실제 인쇄로 확인하지 않았습니다.

- **IGIS 내부 기준:** 지침의 수치 정의(§8)와 리스크 평가 기준을 IGIS 내부 기준과 대조하지 않았습니다.
