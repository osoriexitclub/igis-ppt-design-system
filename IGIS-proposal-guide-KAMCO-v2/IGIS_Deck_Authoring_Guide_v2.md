# IGIS 본문 작성 지침 v2: 메시지 설계와 디자인시스템 활용

## 1. 이 문서의 역할

이 문서는 디자인시스템과 별도로 쓰는 **본문 작성·검수 지침**입니다. 디자인시스템이 "어떻게 보이는가"를 관리한다면, 이 문서는 다음을 관리합니다.

- 무엇을 전달할지
- 어떤 근거가 필요한지
- 어떤 장표 유형과 구성요소를 고를지
- 수치를 어떻게 해석하고 검수할지

**적용 범위는 본문 장표뿐입니다.** 표지(IGIS 01)·목차(IGIS 02)·섹션 간지(IGIS 03)·클로징(IGIS 07)의 서식과 문안 규칙은 이 문서의 대상이 아닙니다.

이 문서는 IGIS의 공식 내부 작성 규정을 확인해 만든 것이 아닙니다. 컨설팅 보고서의 표현 원칙과 투자·자산운용 보고의 특성을 반영한 보완 지침입니다. 확인되지 않은 IGIS 내부 기준이나 의사결정 권한을 새로 정의하지 않습니다.

### 문서 간 관계

| 문서 | 관리 내용 | 위치 |
|---|---|---|
| 디자인시스템 v2 | 색·서체·로고·레이아웃·구성요소의 **시각 규칙** | `README.md`, `body-components.md`, `slide-types.md`, `tokens.json`, `templates/`, `body/` |
| 본 작성 지침 | 독자 질문, 메시지, 근거, **구성요소 선택**, 수치 검수, 논리 점검 | 이 문서 |
| 변경 원칙 | 고정 층과 확장 층, 예외 판단 절차 | `change-policy.md` |
| 변경 내역 | v2에서 바뀐 것과 근거 | `CHANGELOG_v2.md` |

같은 시각 규칙을 두 문서에 적지 않습니다. 이 문서는 시각 규칙이 필요할 때 디자인시스템의 ID와 위치만 가리킵니다.

## 2. 디자인시스템을 참조하는 방법

### 참조 ID 체계 (모두 실제로 존재하는 항목)

| 표기 | 대상 | 정의 위치 |
|---|---|---|
| `IGIS 04` `IGIS 04b` `IGIS 05` `IGIS 06` | PowerPoint 본문 레이아웃 | `templates/IGIS-KAMCO-template.potx`, `README.md` "레이아웃" |
| `S1`~`S4`, `N1`~`N12`, `N5b`, `C1`~`C4`, `R1`~`R6`, `P1`~`P4`, `K1`~`K2`, `D1`~`D4` | 본문 장표 유형 | `slide-types.md` |
| `BC-01`~`BC-09` (변형 `BC-06a`~`BC-06d`) | 본문 구성요소 | `body-components.md` §2 |
| `BP-1`~`BP-6` | 본문 정보 구성 패턴 | `body-components.md` §4, HTML 견본 `body/bp*.html` |
| 하드 룰 1~9 | 브랜드 고정 규칙 | `README.md` "하드 룰" |

`R1`~`R6`은 장표 유형(조직도 등)입니다. 외부 참고자료는 `REF-R1`~`REF-R6`로 씁니다.

### 참조 순서

1. 내용 유형(§6)을 정하고, 그 항목의 **참조** 줄에 적힌 유형·패턴·구성요소를 씁니다.
2. 적합한 것이 여러 개면 독자의 질문과 비교 구조에 가장 맞는 것을 고릅니다.
3. 맞는 것이 없으면 기존 표·차트·텍스트 구성요소의 조합으로 표현할 수 있는지 먼저 검토합니다.
4. 새 서식이 필요하면 `change-policy.md`의 본문 서식 예외 절차를 따릅니다. 장표에서 임의로 서식을 바꾸지 않습니다.
5. 공간이 모자라면 스타일 변경보다 문장 축약, 정보 선별, 장표 분리를 먼저 합니다.

## 3. 작성 전 정의할 다섯 가지

1. **독자:** 투자위원회, 경영진, 내부 실무자, 외부 투자자, 평가위원 중 누구인가?
2. **질문:** 이 자료를 읽은 사람이 이해하거나 판단해야 할 한 가지는 무엇인가?
3. **결론:** 현재 근거로 어디까지 확실하게 말할 수 있는가?
4. **근거:** 필요한 수치, 비교 기준, 출처와 기준일이 확보돼 있는가?
5. **한계:** 미확인 사항, 가정, 제외 범위가 결론에 어떤 영향을 미치는가?

외부 투자자·평가위원용 문서는 내부 의사결정용 문구를 그대로 옮기지 않습니다. 내부 권고와 대외 사실 설명을 구분하고, 승인되지 않은 약속·성과 보장·확정 표현을 추가하지 않습니다.

## 4. 메시지 유형 정하기

> v1 `slide-types.md` 1단계에서 옮겨 왔습니다.

슬라이드 제목(결론 문장)을 먼저 쓰고, 그 문장이 무엇을 주장하는지로 분류합니다. 아래 예시 제목은 형식 예시이며 사실 주장이 아닙니다.

| 제목이 말하는 것 | 메시지 유형 | 예시 제목 | 해당 내용 유형 (§6) |
|---|---|---|---|
| 우리가 무엇을 제안·약속하는가 | **요약·주장** | "3대 운용 원칙으로 회수율을 극대화합니다" | I |
| 숫자가 얼마인가, 얼마나 변했는가 | **수치** | "운용자산은 5년간 2.1배 성장" | A, C, D, J |
| 무엇이 더 나은가, 어떻게 다른가 | **비교** | "당사 안은 비용·기간 모두 우위" | B, I |
| 무엇으로 이루어져 있는가, 누가 무엇을 하는가 | **구조** | "전담 조직 3개 팀이 단계별로 책임" | E |
| 어떤 순서로, 언제 진행하는가 | **과정·일정** | "12개월 내 3단계로 정상화" | F |
| 무엇이 위험하고 어떻게 대응하는가 | **리스크·대응** | "주요 리스크 4종에 대응책 확보" | G |
| 조건이 바뀌면 결과가 어떻게 달라지는가 | **시나리오** | "금리 1%p 상승 시 IRR은 1.4%p 하락" | H |
| 사실·조건을 정확히 보여 준다 | **상세·근거** | "대상 자산 개요" | B, C |

## 5. 사실·해석·가정·전망·권고의 구분

| 구분 | 정의 | 문장 형식 | 장표 표기 |
|---|---|---|---|
| 사실 | 출처로 확인된 값·사건 | "~했습니다", "~입니다" | 태그 없음. 출처는 푸터·BC-05 |
| 해석 | 사실에서 작성자가 끌어낸 판단 | "~로 보입니다", "~로 판단합니다" | BC-04 항목 태그 `해석` |
| 가정 | 계산·전망의 전제로 둔 조건 | "~를 가정했습니다" | BC-04 태그 `가정`, 또는 가정 표(BC-06a) |
| 전망 | 미래 값·상황의 예상 | "~할 것으로 예상합니다" + 근거 모델 | 값 뒤 `(F)`, 추정은 `(E)` (`body-components.md` §3) |
| 권고 | 작성자가 제안하는 선택 | "~를 권고합니다" | BC-04 태그 `권고`. 승인 여부와 구분 |
| 한계 | 결론을 제약하는 미확인·제외 사항 | "~는 확인되지 않았습니다" | BC-04 태그 `한계` + BC-05 주석 |

- 상관관계를 인과관계로 쓰지 않습니다. 원인이 확인되지 않으면 `해석` 또는 `한계`로 씁니다.
- 한 문장에 사실과 해석을 섞지 않습니다.

## 6. 내용 유형별 작성과 구성요소 선택

각 유형의 **참조** 줄은 디자인시스템 v2에 실제로 있는 항목입니다. `(신규 v2)` 표시는 이번에 추가된 항목입니다.

### A. 시장의 변화나 추세

- **독자의 질문:** 무엇이 얼마나 달라졌으며, 그 변화가 지속되는가?
- **제목의 결론:** 대상 + 방향·크기 + 비교 기간. 예: "서울 오피스 거래금액은 2년 감소 후 2024년 18% 증가" (가상).
- **필요한 데이터·근거:** 같은 정의의 시계열, 기준 기간, 단위, 실적·추정·전망 구분, 전환점의 원인 근거.
- **참조:**
  - 유형: `N1` 추이(8기간 이하), `N2` 추이(장기). 지표가 2개 이상이면 `BP-3` (신규 v2)
  - 패턴: `BP-1` 단일 근거형 (신규 v2) — 견본 `body/bp1-single.html`
  - 구성요소: `BC-01` 도표 머리말, `BC-02` 증감 라벨, `BC-04` 해석 블록, `BC-05` 주석·출처 블록 (모두 신규 v2)
  - 레이아웃: `IGIS 06` 또는 `IGIS 04b`
- **선택 이유·적용 조건:**
  - 막대(N1)는 기간별 크기 비교가 중요하고 8기간 이하일 때 씁니다.
  - 선(N2)은 기간이 많고 흐름이 중요할 때 씁니다. 계열이 3개 이상이면 패널을 나눕니다(BC-07).
  - 추정·전망 기간이 섞이면 `body-components.md` §3 "실적·추정 구분"을 따릅니다.
- **피할 표현:**
  - 유리한 구간만 잘라 추세를 과장
  - 일회성 요인을 추세로 표현
  - "급증", "폭락" 같은 수식어만 쓰고 수치를 빠뜨림
- **검수:**
  - 증감률 계산 구간이 제목·라벨·본문에서 같은가?
  - 시계열 중간에 정의나 표본이 바뀌지 않았는가? 바뀌었다면 BC-05에 적었는가?
  - 막대가 0 기준선에서 시작하는가?
- **참고 관찰:** REF-R2 PDF 9쪽(제목에 변화 방향·크기·비교 기간 포함), REF-R6 PDF 6쪽. 원본의 시장 결론을 현재 사실로 쓰지 않습니다.

### B. 지역·자산·전략·사업장 비교

- **독자의 질문:** 무엇이 다르고, 어떤 기준에서 상대적으로 유리한가?
- **제목의 결론:** 가장 중요한 차이와 그 비교 기준. 예: "임대료 상승은 강남·여의도에 집중되고 도심은 0.3%로 정체" (가상).
- **필요한 데이터·근거:** 같은 지표, 같은 기준일, 비교 가능한 정의와 범위(면적 기준, 통화, 기간).
- **참조:**
  - 유형: `N5` 순위 비교, `N5b` 항목 × 2개 시점 비교 (신규 v2), `C1` 2-패널, `C3` 비교 표, `D1` 데이터 표
  - 패턴: 패턴과 정확한 값이 모두 필요하면 `BP-4` 패턴+상세형(견본 `body/bp4-pattern-detail.html`). 두 대상의 대조는 `BP-2` 대조형(견본 `body/bp2-contrast.html`) (모두 신규 v2)
  - 구성요소: `BC-01`, `BC-03` 보조 지표 행, `BC-06a` 데이터 표, `BC-07` 복수 패널 (모두 신규 v2)
- **선택 이유·적용 조건:**
  - 패턴이 중요하면 차트, 정확한 값이 중요하면 표를 앞세웁니다.
  - 둘 다 필요하면 BP-4로 차트는 패턴, 표는 정확한 값을 맡깁니다. 같은 값을 차트 라벨·표·본문에 반복하지 않습니다.
  - 범주별 두 번째 지표(공실률 등)는 이중축 대신 BC-03을 씁니다.
- **피할 표현:**
  - 절대 규모와 비율을 섞어 우열 판단
  - 서로 다른 기준일·통화의 값을 같은 표에 둠
  - 기준을 밝히지 않은 "우수", "유리"
- **검수:**
  - 범주 순서가 차트와 표에서 같은가?
  - 합계·평균 행의 산식(합계 / 가중평균)을 BC-05에 적었는가?
  - 강조한 범주가 제목의 주장과 일치하는가?
- **참고 관찰:** REF-R1 PDF 10쪽(국가별 비교 차트 + 하단 보조 수치 행 + 하단 해석 블록), REF-R3 PDF 5쪽(차트는 패턴, 표는 정확한 값).

### C. 펀드·사업의 현재 상태 요약

- **독자의 질문:** 현재 어디에 있으며, 목표나 전기 대비 무엇이 달라졌는가?
- **제목의 결론:** 핵심 현황과 주목할 편차. 예: "집행·회수는 2년 감소 뒤 반등했으나 신규 모집은 23% 감소" (가상).
- **필요한 데이터·근거:** 기준일, 핵심 지표(§8 정의 확인), 비교 대상(목표·계획·전기), 주요 변동 사유.
- **참조:**
  - 유형: `S4` KPI 하이라이트(PPT 샘플 04), `D1` 데이터 표, `N1` + `BC-07` 복수 패널
  - 패턴: 관련 지표 여러 개의 같은 기간 비교는 `BP-3` 복수 지표형 (신규 v2) — 견본 `body/bp3-multi.html`
  - 구성요소: `BC-01`, `BC-02`, `BC-05`, `BC-06a`, `BC-07`
  - 레이아웃: `IGIS 04b`(KPI 행), `IGIS 06`(복수 패널)
- **선택 이유·적용 조건:**
  - 핵심 수치 3~4개로 충분하면 S4를 씁니다.
  - 지표 간 방향이 엇갈리는 것이 메시지면 BP-3에서 같은 기간·같은 척도로 나란히 둡니다.
- **피할 표현:**
  - 같은 숫자를 KPI·차트·본문에 반복
  - 누적값과 당기값 혼용
  - 비교 기준(목표, 계획, 전기)을 밝히지 않은 "달성", "개선"
- **검수:**
  - 규모·성과·유동성 지표를 구분했는가?
  - BC-07 패널의 척도가 같거나, 다르면 표기했는가?
  - 잠정치에 `잠정` 또는 `(E)`를 붙였는가?
- **참고 관찰:** REF-R6 PDF 6쪽(투자·회수·모집 3개 지표를 같은 연도 축으로 정렬, 최신 연도 강조, 공통 주석은 하단). 실제 펀드 현황 양식의 공식 기준은 아닙니다.

### D. 수익·비용·가치의 증감 원인

- **독자의 질문:** 시작값이 종료값으로 바뀐 이유는 무엇인가?
- **제목의 결론:** 전체 변화를 설명하는 주요 요인과 상쇄 요인. 예: "NOI 5.0% 증가는 임대료 인상이 주도했고 비용 증가가 일부 상쇄" (가상).
- **필요한 데이터·근거:** 시작값, 종료값, 요인별 증감, 산식·집계 기준, 요인별 근거(계약·실적).
- **참조:**
  - 유형: `N6` 증감 분해 (기존, PPT 샘플 06)
  - 패턴: `BP-5` 증감 분해형 (신규 v2) — 견본 `body/bp5-decomposition.html`
  - 구성요소: `BC-06c` 증감 분해 표, `BC-08` 도표 내 설명, `BC-04`, `BC-05` (모두 신규 v2)
  - 레이아웃: `IGIS 06`
- **선택 이유·적용 조건:**
  - 요인이 3~6개이고 시작 + 요인 합계 = 종료가 성립할 때 폭포 차트를 씁니다.
  - 정확한 금액·기여도·근거는 BC-06c 표가 맡습니다.
  - 요인이 7개 이상이면 작은 요인을 `기타`로 묶고, 묶은 범위를 BC-05에 씁니다.
- **피할 표현:**
  - 설명되지 않는 잔차를 다른 요인에 끼워 넣음
  - 구성비와 증감 기여도를 혼동
  - 원인이 확인되지 않은 요인을 단정
- **검수:**
  - 시작값 + 요인 합계 = 종료값이 표에서 대사되는가?
  - 같은 효과를 두 요인에 중복 계산하지 않았는가?
  - 기여도 산식(분모)을 표기했는가?
- **구분:**
  - 증감 원인 폭포 차트와 계약상 현금 배분 순서인 **분배 워터폴**은 다른 개념입니다.
  - 분배 워터폴은 E 유형(P1 단계 또는 BC-06a 표)을 씁니다.
- **참고 관찰:** REF-R5 PDF 6쪽(요인 분해 워터폴, 차트 안 설명문, 도표별 주석). 원본의 축 생략(사선 끊김)과 연결 점선은 채택하지 않았습니다 (`CHANGELOG_v2.md`).

### E. 투자 구조·자금 흐름·분배 순서

- **독자의 질문:** 누가 어떤 권리와 의무를 가지며, 자금은 어디로 이동하는가?
- **제목의 결론:** 핵심 관계, 자금 경로, 우선순위·조건. 예: "선순위 대출 상환 후 잔여 현금을 지분 비율대로 배분하는 구조" (형식 예시).
- **필요한 데이터·근거:** 당사자, 지분·대출·계약 관계, 자금 종류(출자·대여·상환·배당), 지급 조건과 순서, 트리거 원문.
- **참조:**
  - 유형: `R6` 투자 구조·자금 흐름 (신규 v2, `body-components.md` §5), 분배 순서는 `P1` 단계 프로세스
  - 구성요소: `BC-06a` 조건 표, `BC-05`
  - 레이아웃: `IGIS 04b`
- **선택 이유·적용 조건:**
  - 소유·계약 관계와 실제 자금 이동을 R6에 정의된 서로 다른 관계선으로 구분할 수 있을 때 씁니다.
  - 주체가 8개를 넘으면 구조도를 나누거나 표로 바꿉니다.
- **피할 표현:**
  - 출자·대여·상환·배당을 같은 선이나 같은 단어로 표시
  - 범례 없는 화살표
- **검수:**
  - 선과 화살표의 의미가 범례로 정의돼 있는가?
  - 계약상 권리와 예상 현금흐름이 혼동되지 않는가?
  - 우선순위·트리거가 계약 원문과 일치하는가?
- **근거:** 투자자료 작성 보완 지침. REF-R1~REF-R6에서 검증한 구조도 사례는 없습니다.

### F. 일정·실행 계획·선행조건

- **제목의 결론:** 핵심 마일스톤과 일정에 영향을 주는 선행조건. 예: "인허가 완료가 2026년 3월 착공의 선행조건" (형식 예시).
- **필요한 데이터·근거:** 기준일, 단계, 확정·예정 구분, 책임 주체, 의존 관계.
- **참조:**
  - 유형: `P2` 일정표 (확정·예정 표기 규칙 신규 v2, `body-components.md` §5)
  - 구성요소: 선행조건 표 `BC-06a`(선행조건 / 책임 주체 / 기한 / 상태), `BC-01`(기준일 표기), `BC-05`
  - 레이아웃: `IGIS 04b`
- **선택 이유·적용 조건:** 병행 과업과 의존 관계가 있으면 P2를 씁니다. 순차 단계만 있으면 P1으로 충분합니다.
- **피할 표현:**
  - 확인되지 않은 완료일을 확정일처럼 표시
  - 기준일 이후 상황을 임의로 현재화
- **검수:**
  - 인허가·계약·자금조달 등 전제조건이 빠지지 않았는가?
  - `확정` / `예정` 라벨이 모든 막대에 있는가?
- **근거:** 투자자료 작성 보완 지침.

### G. 리스크와 대응 방안

- **독자의 질문:** 무엇이 잘못될 수 있고, 영향과 대응의 한계는 무엇인가?
- **제목의 결론:** 핵심 위험과 대응 후에도 남는 위험. 예: "대응 조치를 마련했으나 인허가 지연 위험은 남아 있음" (형식 예시).
- **필요한 데이터·근거:** 위험 사건, 발생 조건, 영향, 대응 수단, 잔여 위험, 확인 가능한 담당·일정.
- **참조:**
  - 유형: `K1` 리스크-대응 표 → 서식 `BC-06d` (신규 v2)
  - 유형: `K2` 리스크 매트릭스 — 공식 평가 기준이 있을 때만
  - 구성요소: `BC-04` 태그 `한계`, `BC-05`
  - 레이아웃: `IGIS 04b` 또는 `IGIS 06`
- **선택 이유·적용 조건:**
  - 위험과 대응을 일대일로 대응시킬 때 K1을 씁니다.

- **피할 표현:**

  - 근거 없는 확률·등급
- **검수:**
  - 이미 발생한 이슈와 미래 위험을 구분했는가?

- **근거:** 투자자료 작성 보완 지침. 공식 위험 평가 기준이 있으면 그 정의를 씁니다.

### H. 시나리오와 민감도

- **독자의 질문:** 어떤 가정이 결과를 좌우하며, 조건이 바뀌면 결과가 어떻게 달라지는가?
- **제목의 결론:** 핵심 변수, 결과의 변동 범위, 판단상 중요한 경계 조건. 예: "Cap Rate가 5.5%를 넘으면 목표 IRR 7%에 미달" (형식 예시).
- **필요한 데이터·근거:** 기준 시나리오, 변수 정의, 변경 범위, 계산 모델과 기준일.
- **참조:**
  - 유형: `N9` 시나리오 → 민감도표 `BC-06b` (신규 v2)
  - 구성요소: 가정 표 `BC-06a`, `BC-04` 태그 `가정`·`해석`, `BC-05`(모델 기준일)
  - 시나리오별 결과 비교: `N5b` 또는 `C1`
  - 패턴: 결과와 가정을 함께 읽게 하려면 `BP-4` 배치를 응용(위 결과, 아래 가정 표)
  - 레이아웃: `IGIS 06`
- **선택 이유·적용 조건:**
  - 변수 2개 조합은 BC-06b를 씁니다.
  - 여러 변수가 함께 바뀌는 시나리오는 시나리오별 열을 둔 BC-06a를 씁니다.

- **피할 표현:**
  - 검증되지 않은 시나리오에 확률 부여
  - 전망을 확정 수익처럼 표현
- **검수:**
  - 모델이 지원하지 않는 수치를 만들지 않았는가?
  - 기준 셀이 실제 기준 시나리오와 일치하는가?
- **근거:** 투자자료 작성 보완 지침.

### I. 선택지 비교와 권고

- **필요한 데이터·근거:** 실행 가능한 대안, 공통 평가 기준, 비용·효과·위험, 미확인 사항.

- **검수:**

  - 모든 대안을 같은 기준으로 평가했는가?
- **근거:** 투자자료 작성 보완 지침.

## 7. 문장의 품질 기준

### 제목

- 한 장의 핵심 결론을 한 문장으로 씁니다. 기본 구조는 **대상 + 변화 또는 차이 + 비교 기준**입니다.
- 제목은 기존 제목 자리에 맞춥니다 (크기·줄 수는 `README.md` "서체"·"캔버스와 존").
  - 넘치면 문장을 줄이거나 내용을 나눕니다.
  - 글자 크기를 줄이지 않습니다 (`README.md` "서체").
- '현황', '분석', '검토'로 끝나는 명사형 제목을 쓰지 않습니다.
  - X: "지역별 투자 현황"
  - O: "투자 규모는 회복됐으나 지역별 회복 속도에는 차이가 있음" (형식 예시)
- 근거가 부족하면 결론을 단정하지 않고 결론의 범위를 좁힙니다.
- 질문형 제목은 아직 판단할 수 없는 쟁점을 드러낼 때만 씁니다.
- 근거 없는 인과관계, 과장된 확신, 밝히지 않은 비교 대상을 넣지 않습니다.
- 제목에서 강조한 대상은 장표 안에서 강조한 막대·셀과 같은 것이어야 합니다.

### 설명문

- 문장마다 역할을 분명히 합니다: 사실, 비교, 해석, 조건 또는 권고 (§5).
- '증가했다'에서 끝내지 않고 비교 기간·규모·주요 차이를 필요한 만큼 씁니다.
- '안정적', '우수한', '매력적', '유의미한' 같은 평가어에는 판단 기준을 붙입니다.
- 추정은 추정으로, 계획은 계획으로, 가능성은 가능성으로 씁니다.
- 전문용어와 약어는 처음 나올 때 정의하고, 같은 개념에 다른 이름을 섞지 않습니다.
- **문체:** 3인칭 기관 화법, -습니다체. 홍보성 표현·감탄사·이모지를 쓰지 않습니다. (v1 `README.md` "문안 원칙"에서 옮김)
- **국·영 병기:** 국문이 주, 영문은 라벨·부제로 병기합니다. (v1 `README.md` "문안 원칙"에서 옮김)

### 표·차트·설명의 역할 분담

| 요소 | 맡는 일 | 디자인시스템 |
|---|---|---|
| 차트 | 추세·차이·구성·분포 같은 패턴 | `slide-types.md` N 유형 |
| 표 | 정확한 값, 세부 항목, 비교 조건 | `BC-06` |
| 해석 블록 | 도표에서 읽히는 결론, 중요한 예외, 투자 판단상 의미 | `BC-04` |
| 주석·출처 | 해석에 필요한 조건과 자료 | 푸터 + `BC-05` |

- 주요 수치만으로 결론이 충분하면 세부 정보를 늘리지 않습니다. 상세는 별첨(D4)으로 분리합니다.

| 근거 없는 확신 | '리스크가 해소됐다' | '대응 조치를 마련했으나 인허가 지연 위험은 남아 있음' |
| 수치 반복 | '비용이 증가했다' | '금융비용 증가가 총비용 상승의 주요 요인이며 다른 비용 감소가 이를 일부 상쇄' |

고친 문장도 해당 근거가 있을 때만 씁니다. 형식 예시를 사실 대신 쓰지 않습니다.

## 8. 투자·자산운용 수치 검수

아래는 확인 항목입니다. 특정 펀드의 정의나 내부 회계 기준을 대신하지 않습니다. 숫자의 **표시 형식**(정렬, 자릿수, 음수 부호, `(E)`·`(F)`)은 `body-components.md` BC-02·BC-06과 §3을 따릅니다.

- **금액:** 통화, 표시 단위(원·백만원·억원), 환율과 적용일.
- **규모:** 약정액, 납입액, 투자집행액, 미집행 약정, NAV, AUM의 정의와 범위.
- **기간:** 기준일 현재 잔액, 기간 중 흐름, 설정 이후 누적값의 구분.
- **수익률:**
  - IRR과 단순 수익률
  - Gross와 Net
  - 실현과 미실현
  - 레버리지 반영 여부
- **성과 배수:**
  - MOIC·TVPI·DPI·RVPI의 정의와 분자·분모
  - 펀드·투자자·개별 자산 수준의 구분
  - 같은 범위·기준일에서 정의상 연결되는 값은 대사합니다 (예: TVPI = DPI + RVPI).
- **부동산 지표:** NOI·Cap Rate·LTV·DSCR의 산식, 적용 기간, 가치·부채 범위와 평가 기준.
- **운영 지표:** 임대율·공실률의 면적 기준, 계약 기준과 실제 입주·수취 기준의 구분.
- **합계:** 세부 합계와 총계, 비율 합계, 증감 연결, 반올림 차이, 중복 집계.
- **증감 표현:**
  - 증감률(%)과 차이(%p)를 구분합니다.
  - 배수는 `1.4배`로 씁니다.
  - 기준 시점을 라벨이나 머리말에 둡니다 (BC-02).
- **계획·예측:** 가정, 모델 기준일, 실제 실적과의 구분, 민감한 변수.

정의가 다른 수치를 같은 이름으로 맞추지 않습니다. 확인되지 않은 값은 사실로 채우지 않고, 결론에 필수라면 확인 사항으로 분리합니다. 핵심 근거가 부족하면 완성된 투자 판단으로 제시하지 않습니다.

## 9. 개별 본문 장표의 품질 점검

각 장표에서 다음이 성립해야 합니다. 이 점검표를 화면에 표시할 필요는 없습니다.

1. 독자의 질문이 특정돼 있다.
2. 제목이 질문에 답하거나, 답할 수 없는 이유를 정확히 보여 준다.
3. 핵심 근거가 제목의 주장을 뒷받침한다.
4. 고른 유형·패턴·구성요소가 §6의 참조와 맞는다.
5. 사실·해석·가정·전망·권고가 구분된다 (§5).
6. 단위·기준일·출처·중요 조건이 푸터와 BC-05에 있다.
7. 같은 정보가 차트·표·문장에 반복되지 않는다.
8. 디자인시스템에 있는 ID만 쓰고, 없는 구성요소를 만들지 않았다.
9. 서식 예외가 있다면 `change-policy.md` 절차에 따라 기록돼 있다.

## 10. 본문 전체의 논리 점검

- 본문 제목만 이어 읽어도 문제 → 근거 → 해석 → 판단(또는 남은 쟁점)의 흐름이 이해되는가?
- 앞 장표의 결론이 뒤 장표에서 근거 없이 바뀌지 않는가?
- 같은 지표·지역·자산의 명칭, 단위, 기준일이 전체에서 일관되는가?
- 시장의 일반적 사실을 개별 자산이나 펀드의 성과 근거로 과도하게 확장하지 않는가?
- 핵심 리스크와 반대 근거를 뒤쪽의 작은 주석에만 두지 않았는가?
- 독자가 내려야 할 판단과 아직 확인이 필요한 사항이 구분되는가?
- 제목만 강하고 실제 근거는 약한 구성이 없는가?
