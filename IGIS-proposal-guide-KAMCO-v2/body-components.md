# 본문 구성요소와 정보 구성 패턴

본문 장표의 **시각적 구현 규칙**을 관리하는 섹션입니다. 어떤 내용에 어떤 구성요소를 고르는지는 `IGIS_Deck_Authoring_Guide_v2.md`(이하 작성 지침)에서 관리합니다.

- **적용 범위:** 본문 장표만. 표지(IGIS 01)·목차(IGIS 02)·섹션 간지(IGIS 03)·클로징(IGIS 07)에는 쓰지 않습니다.
- **값의 출처:** 이 문서의 모든 색·글자 크기·선 굵기는 `tokens.json`의 기존 토큰입니다. 이 섹션을 위해 토큰을 추가하거나 바꾸지 않았습니다.
- **상태 표기:**
  - **기존:** v1에 있던 요소. 이름과 위치를 그대로 씁니다.
  - **신규 (v2):** 이번에 추가한 요소. 변경 근거는 `CHANGELOG_v2.md`에 있습니다.
- **좌표 단위:** 1280×720 캔버스 px (pt = px × 0.75).

## 2. 신규 본문 구성요소 (v2)

### BC-01 도표 머리말 (신규)

도표 하나하나에 붙는 이름과 단위 줄입니다.

- **형식:** `도표명, 기준·범위 단위` 한 줄. 예: `오피스 거래금액, 서울, 조원`
  - 도표명: 13pt(17px) Medium NAVY
  - 쉼표 뒤 기준·단위: 13pt Regular GRAY
- **위치:** 도표 그리기 영역 바로 위, 도표 블록 왼쪽 끝에 맞춥니다. 아래 도표와 간격 8px.
- **필수 조건:** 한 장에 도표가 2개 이상이거나, 도표의 단위가 푸터의 공통 단위와 다를 때. 도표가 1개이고 단위가 푸터와 같으면 생략할 수 있습니다.
- **허용 변형:** 두 줄째에 기간·추정·척도 표기를 둘 수 있습니다 (예: `2019–2025, 2025년은 (E)`). 두 번째 줄은 10.5pt Regular GRAY. 최대 2줄.
- **금지:** 색 배경 띠, 대문자 라벨 장식, 번호 배지.

### BC-02 증감 라벨 (신규)

비교 기준 대비 변화를 숫자로 직접 적는 텍스트 라벨입니다.

- **형식:** 증감률 `+18%`, 차이 `+1.2%p`, 배수 `1.4배`. 음수 부호는 `−`(U+2212).
- **서체:** 10.5pt(14px) SemiBold. 강조 대상이면 BLUE, 아니면 NAVY.
- **위치:** 비교 대상 중 나중 시점(또는 강조 대상) 막대의 값 라벨 위 4px.
- **비교 기준 표기:** 무엇 대비인지가 머리말이나 축에서 드러나지 않으면, 라벨 바로 위에 9pt Regular gray-500으로 `전년 대비`처럼 씁니다.
- **금지:** 꺾쇠·화살표·연결선·원형 배지. 텍스트만 씁니다 (하드 룰 7, 장식 선 금지).
- **개수:** 도표당 최대 3개.

### BC-03 보조 지표 행 (신규)

막대 도표의 각 범주에 딸린 두 번째 지표(비율 등)를 축 아래 한 줄로 정렬한 행입니다.

- **용도:** 같은 범주에 대해 단위가 다른 지표를 함께 보여 줄 때. 이중축 대신 씁니다.
- **형식:**
  - 행 이름: 왼쪽 레일, 10.5pt SemiBold NAVY (예: `공실률`)
  - 값: 각 범주 막대 중심에 맞춰 10.5pt Regular GRAY. 강조 범주만 BLUE SemiBold
  - 행 위 구분선: `gray-300` 0.75pt
- **개수:** 최대 2행.

### BC-04 해석 블록 (신규, 기존 문체 요소의 조합)

도표가 보여 주는 결론·예외·의미를 적는 블록입니다. 샘플 04의 본문 2단과 2-패널의 "SemiBold 핵심어 + 설명" 형식을 규칙으로 정리했습니다.

- **항목 형식:** SemiBold NAVY 핵심어 문장 + Regular GRAY 설명. 13pt(17px), 밀도가 높으면 12pt(16px). 줄 간격 1.35.
- **배치 변형:**
  - **하단형:** 도표 아래 전폭에 2~3단. 블록 위 `gray-300` 0.75pt 선, 선과 글 사이 12px.
  - **측면형:** 도표 오른쪽 4/12 또는 3/12 폭, 항목을 세로로. 항목 사이 `gray-300` 0.75pt 선.
  - **좌측 제목형 (하단형 변형):** 왼쪽 3/12에 16.5pt SemiBold NAVY 블록 제목, 오른쪽 9/12에 항목.
- **항목 머리 태그 (선택):** 사실이 아닌 항목은 핵심어 앞에 `해석` `가정` `전망` `권고` `한계` 중 하나를 SemiBold gray-500으로 붙입니다. 태그가 없는 항목은 확인된 사실입니다. 어떤 태그를 쓰는지는 작성 지침 §5에서 정합니다.
- **정보량:** 최대 3항목, 항목당 최대 3줄.
- **금지:** 색 배경 상자, 아이콘, 따옴표 장식.

### BC-05 주석·출처 블록 (신규)

푸터 한 줄에 담을 수 없는 해석 조건을 적는 블록입니다.

- **푸터와의 역할 분담:**
  - 기존 푸터 왼쪽(변경 없음): 공통 출처·단위·기준일을 그대로 씁니다.
  - BC-05: 정의·산식·제외 항목·표본·환율·반올림 등 **조건**을 씁니다.
- **형식:** 9pt(12px) Regular gray-500, 줄 간격 1.3. 줄 머리에 `주:` / `자료:` / `표본:` / `환율:`.
- **위치:** 콘텐츠 영역 맨 아래. 마지막 줄이 680px에서 끝나게 둡니다. 위 콘텐츠와 간격 12px 이상.
- **정보량:** 최대 3줄. 넘치면 별첨 장표로 보내고 `주: 상세 정의는 별첨 A-2`처럼 씁니다.
- **도표별 조건:** 한 도표에만 해당하면 그 도표 바로 아래에 같은 서식으로 1줄 둡니다. 여러 도표의 공통 조건만 BC-05에 둡니다.
- **금지:** 8pt 이하, Light 굵기, 회색 배경.

### BC-06 데이터 표 (신규, 카탈로그 D1·D4·K1·C3·N9의 표 서식)

v1에서 "정의"로만 남았던 표 서식입니다. 목차 표(IGIS 02)와 KPI 행에서 쓰던 선 체계를 표 전체로 확장했습니다.

| 요소 | 규칙 |
|---|---|
| 표 상단 | NAVY 1.25pt 선 |
| 머리글 행 | 10.5pt SemiBold NAVY, 아래 NAVY 0.75pt 선. 단위는 머리글 안에 `(억원)`처럼 |
| 행 구분 | `gray-300` 0.75pt 선. 세로선 없음. 줄무늬 채움 없음 |
| 본문 셀 | 10.5pt Regular GRAY. 별첨(D4)은 하한 9pt |
| 숫자 | 오른쪽 정렬, 고정폭 숫자, 천 단위 쉼표. 같은 열은 소수 자릿수 통일. 음수는 `−` |
| 문자 | 왼쪽 정렬 |
| 행 머리글 (첫 열) | 10.5pt Medium NAVY, 왼쪽 정렬 |
| 강조 셀 | BLUE SemiBold 글자. 채움 없음. 표당 최대 3셀 또는 1열 |
| 합계 행 | SemiBold NAVY, 위에 NAVY 0.75pt 선 |
| 묶음 머리 | 10.5pt Medium NAVY 행, 위 12px 여백 (예: 권역명) |
| 추정·전망 | 값 뒤에 `(E)` `(F)`, 또는 열 머리글에 표기 |
| 행 높이 | 최소 24px (10.5pt), 별첨 20px (9pt) |

변형:
- **BC-06a 기본 표:** 위 규칙 그대로.
- **BC-06b 민감도표 (N9):** 행·열 머리글이 변수값. 기준 시나리오 셀만 BLUE SemiBold, 셀 테두리 없이 행 구분선만.
- **BC-06c 증감 분해 표 (N6와 짝):** 열 = 요인 / 금액 / 기여도(%p) / 설명. 마지막 행은 합계. 시작값 + 요인 합계 = 종료값이 표 안에서 확인돼야 합니다.
- **BC-06d 리스크-대응 표 (K1):** 열 = 리스크 / 발생 조건 / 영향 / 대응 / 잔여 위험 / 담당. 텍스트 열은 왼쪽 정렬.

### BC-07 복수 패널 정렬 (신규, 스몰 멀티플)

관련 지표 여러 개를 같은 기준으로 나란히 놓는 규칙입니다.

- **배치:** 2~4개 패널을 같은 폭으로 가로 배열. 패널 사이 40px (`gap-block`).
- **머리말:** 패널마다 BC-01을 둡니다.
- **공통 축:** 가로축(기간·범주)의 범위와 순서를 모든 패널에서 같게 둡니다.
- **세로축:**
  - 단위가 같은 패널은 같은 척도를 씁니다.
  - 척도를 달리해야 하면 BC-01 두 번째 줄에 `패널별 척도 다름`이라고 씁니다.
- **강조:** 모든 패널에서 같은 시점·범주를 BLUE로 칠합니다 (예: 최신 연도). 증감 라벨(BC-02)도 같은 위치에 둡니다.
- **주석:** 공통 조건은 BC-05 한 곳에, 패널별 조건은 해당 패널 아래에 둡니다.

### BC-08 도표 내 설명 (신규)

도표 안 빈 영역에 해당 막대·구간을 설명하는 짧은 문장입니다.

- **형식:** 10.5pt Regular GRAY, 최대 2줄, 왼쪽 정렬.
- **위치:** 설명 대상 막대에 가장 가까운 빈 영역. 막대·값 라벨과 8px 이상 떨어뜨립니다.
- **개수:** 도표당 최대 2개.
- **금지:** 상자, 지시선, 화살표, 말풍선.

### BC-09 교차 비교 표 (신규, 카탈로그 N12)

두 범주(예: 자산 유형 × 투자자 유형)를 교차한 값 표입니다. 버블 차트·색 단계 히트맵을 대신합니다.

- **서식:** BC-06 규칙을 따릅니다. 행 머리글 열 오른쪽에 `gray-300` 0.75pt 세로선 하나를 허용합니다 (행 머리와 값 구분).
- **강조:** 열마다 최댓값 셀을 BLUE SemiBold로 칠하거나, 기준값 이상 셀만 칠합니다. 어느 기준으로 강조했는지 BC-05에 적습니다.
- **채움:** 색 단계 채움은 쓰지 않습니다 (팔레트 외 색조가 필요하고, 흑백 인쇄 시 단계가 구분되지 않습니다).
- **합계·전체 열:** 맨 왼쪽 값 열에 두고 SemiBold로 씁니다.
- **크기:** 최대 8행 × 6열 (10.5pt). 넘치면 별첨.

## 4. 본문 정보 구성 패턴 (신규, BP-1 ~ BP-6)

기존 레이아웃 위에 구성요소를 배치하는 6가지 패턴입니다. 새 레이아웃(마스터)을 만들지 않았습니다. HTML 견본은 `body/` 폴더에 있으며, 모두 **가상 예시 데이터**를 씁니다.

| ID | 패턴 | 사용 레이아웃 | 배치 (12-컬럼, 블록 간격 40px) | 구성요소 | 견본 |
|---|---|---|---|---|---|
| BP-1 | 단일 근거형 | IGIS 06 또는 04b | 도표 8/12 + 해석 블록 측면형 4/12 | BC-01·02·04·05 | `body/bp1-single.html` |
| BP-2 | 대조형 | IGIS 05 또는 06 | 6/6, 같은 척도의 도표 2개 + 각 도표 아래 해석 1~2줄 | BC-01·02·05·07 | `body/bp2-contrast.html` |
| BP-3 | 복수 지표형 | IGIS 06 | 3~4개 패널 같은 폭 + 하단형 해석 블록 | BC-01·02·04·05·07 | `body/bp3-multi.html` |
| BP-4 | 패턴+상세형 | IGIS 06 | 위 도표(콘텐츠 높이의 약 45%) + 아래 데이터 표 | BC-01·03·06a·05 | `body/bp4-pattern-detail.html` |
| BP-5 | 증감 분해형 | IGIS 06 | 폭포 차트 7/12 + 증감 분해 표 5/12 + 하단 해석 | N6·BC-06c·08·04·05 | `body/bp5-decomposition.html` |
| BP-6 | 교차 비교형 | IGIS 06 | 교차 비교 표 8/12 + 해석 블록 측면형 4/12 | BC-09·04·05 | `body/bp6-cross.html` |

공통 규칙:
- 패널 수·좌표를 원본 보고서에 맞추지 않습니다. 내용에 필요한 만큼만 씁니다.
- 한 장에 BP 하나만 씁니다. 두 패턴이 필요하면 장을 나눕니다.
- 모든 패턴은 푸터 왼쪽에 출처·단위·기준일을 씁니다 (하드 룰 4, 변경 없음).

## 5. 신규 구조 장표 시각 규칙 (v2)

### R6 투자 구조·자금 흐름도 (신규, 견본 없음)

- **주체 상자:** 흰 바탕 + `gray-300` 0.75pt 테두리, 모서리 0. 주체명 10.5pt Medium NAVY, 역할 9pt Regular GRAY. 당사(IGIS) 상자만 NAVY 1.25pt 테두리.
- **관계선 (의미별로 구분하고 범례 필수):**

  - 계약: GRAY 0.75pt 파선 + 계약명 라벨
