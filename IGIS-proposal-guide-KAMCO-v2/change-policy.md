# 변경 원칙 — 무엇을 지키고 무엇을 늘리는가

이 가이드의 목표는 **누가 만들어도 같은 수준의 균일한 덱**입니다. 그래서 규칙을 두 층으로 나눕니다.

- **고정 층:** 서식과 IGIS 디자인 원칙. 새 인풋이 들어와도 바뀌지 않습니다.
- **확장 층:** 본문 장표의 시각화 방식. 새 인풋을 적극 반영해 계속 늘립니다.

## 적용 제외 페이지 (v2)

**표지(IGIS 01)·목차(IGIS 02)·섹션 간지(IGIS 03)·클로징(IGIS 07)** 에는 확장 층의 변경과 아래 "본문 서식 예외"를 적용하지 않습니다.

- 금지 대상: 레이아웃, 서체, 색상, 로고, 장식 요소, 사용 규칙의 변경.
- 간접 영향도 금지: 공통 토큰(`tokens.json`)·테마·슬라이드 마스터를 본문 개선 목적으로 바꾸지 않습니다.
- 필요한 규칙은 본문 전용으로 분리합니다 (`body-components.md`).

## 확장 층 (인풋을 반영해 계속 늘림)

| 영역 | 늘리는 방법 |
|---|---|
| 본문 장표 유형 | `slide-types.md` 카탈로그에 새 유형 추가 |
| 본문 구성요소·패턴 | `body-components.md`에 BC·BP 항목 추가 (v2) |
| 차트 유형·변형 | 카탈로그의 데이터 유형별 규칙에 추가 |
| 표 변형 | 밀도·강조 방식 변형 추가 (BC-06) |
| 다이어그램 | 조직도, 체계도, 프로세스 등 도형 조합 추가 |
| 아이콘 | 한 세트를 정해 추가 (선 굵기 일정, 단색) |
| 예시 문안 | 유형별 좋은 제목·본문 예시 추가 (작성 지침) |

확장 층의 모든 추가물은 **고정 층의 토큰만으로** 만듭니다. 새 색, 새 서체, 새 효과를 들여오지 않습니다.

## 인풋 반영 절차

개선 문서(md)와 레퍼런스 파일이 들어오면 다음 순서로 처리합니다.

1. **분류:** 각 요청과 레퍼런스를 고정 층인지 확장 층인지 나눕니다.
2. **구조만 가져오기:** 레퍼런스에서는 **정보 구조**(배치, 비교 방식, 데이터 표현 방식)만 가져옵니다. 색·서체·효과·장식은 버리고 IGIS 토큰으로 다시 입힙니다.
   - 예: 그라데이션 배경의 3단 카드 레퍼런스 → 흰 배경 + 3단 그리드 + NAVY 룰로 재구성
3. **카탈로그 대조:** 기존 유형으로 표현되면 그 유형을 쓰거나 변형으로 추가합니다. 표현되지 않으면 새 유형을 만듭니다.
4. **새 유형 등록 조건:** 아래를 모두 채워야 카탈로그에 올립니다.
   - 언제 쓰는지 (데이터 성격, 논리 구조, 메시지 유형)
   - 언제 쓰지 않는지 (비슷한 유형과의 구분)
   - 그리드 배치 (12-컬럼 기준)
   - 최대 정보량 (항목 수, 글자 수, 하한 글자 크기)
   - 샘플 슬라이드 1장 (템플릿 샘플 덱 또는 `body/` HTML 견본)
   - 인쇄 점검 (흑백 인쇄 시 구분 가능한지)
5. **충돌 처리:** 요청이 고정 층과 충돌하면 반영하지 않고 충돌 내용을 보고합니다. "원칙 변경"이 명시된 경우에만 고정 층을 바꿉니다.
6. **기록:** 아래 변경 기록에 날짜, 출처(파일명), 반영 내용을 남깁니다.

## 본문 서식 예외 절차 (v2)

출처: 보완 참고자료 `Claude_Deck_Design_System_Brief.md` §2.3·2.4. **본문 장표에만** 적용합니다.

**기본 원칙**
- 디자인·서식은 기존 규칙을 기본으로 유지합니다.
- 본문 내용의 표현(제목, 메시지–근거 연결, 비교 기준, 표·차트·설명의 역할, 주석·출처의 내용)은 보완 참고자료와 작성 지침을 우선합니다.
- 내용상 우선순위가 서식 변경을 자동으로 허용하지는 않습니다.

**예외로 본문 서식 규칙을 보완·갱신할 수 있는 경우**
1. **미규정:** 실제 기존 문서를 확인한 결과, 필요한 본문 서식 규칙이 없는 경우.
   - 기존 문서를 읽지 못한 것은 미규정이 아닙니다.
2. **실질적 개선:** 같은 내용·데이터를 기준으로 명확성·가독성·비교 용이성·해석 정확성이 실제로 나아지는 경우.
   - 기존 방식의 구체적 문제와 개선 효과를 설명할 수 있어야 합니다.

**판단 기준**
- 단순한 취향이나 외부 브랜드(컨설팅사) 서식 모방은 근거가 아닙니다.
- 기존 IGIS 구성요소로 구현하는 방법을 먼저 검토하고, 필요한 최소 범위만 바꿉니다.
- 로고·지정 서체·브랜드 색상 등 BI 고유 규정과 명시적 사용 제한(하드 룰 1~9)은 이 예외로 바꾸지 않습니다.
- 근거가 부족하면 기존 규칙을 유지합니다.
- 예외가 다른 페이지 유형이나 공통 마스터·토큰으로 퍼지지 않게 합니다 (위 "적용 제외 페이지").

**기록 의무:** 채택한 예외마다 다음을 `CHANGELOG_v2.md` 형식으로 남깁니다.
- 대상 규칙
- 기존 문제 또는 규정 부재
- 새 규칙
- 개선 근거
- 본문 적용 범위
