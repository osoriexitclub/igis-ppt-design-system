# 본문 장표 유형 카탈로그

본문 장표 유형별 **시각 구현 규칙과 사용 조건**입니다. 이 카탈로그는 확장 층이며, 인풋이 들어올 때마다 유형을 추가합니다 (`change-policy.md`).

> **v2 변경:** 메시지 유형 판단(구 1단계)과 빠른 선택표는 작성 지침(`IGIS_Deck_Authoring_Guide_v2.md` §4, §11)으로 옮겼습니다. 이 문서에는 어떤 데이터 조건에서 쓸 수 있는지와 어떻게 그리는지만 둡니다. 구성요소(BC-xx)와 패턴(BP-x)의 세부 규칙은 `body-components.md`에 있습니다.

- **상태 표기:**
  - **구현:** PPT 샘플 덱 또는 HTML 견본(`body/`)에 예시가 있습니다.
  - **정의:** 규칙만 있습니다.
  - **(신규 v2):** 이번에 추가한 유형이나 규칙입니다.
- **ID 주의:** 구조 유형 R1~R6은 장표 유형 ID입니다. 외부 참고자료는 `REF-R1`~`REF-R6`로 구분해 씁니다.

**차트 공통 규칙** (v1 유지)
- 강조는 BLUE 1개 계열 또는 1개 막대. 나머지는 `gray-300`, 보조 구분은 `gray-200`.
- 값 라벨을 직접 붙이고 눈금선·범례는 꼭 필요할 때만 둡니다. 범례 대신 계열 끝에 이름을 씁니다.
- 축 라벨 9pt 이상, 값 라벨 10pt 이상, SemiBold.
- **쓰지 않는 차트:** 3D 차트, 방사형, 버블, 그라데이션 영역 차트. 파이·도넛은 항목 3개 이하이고 한 항목의 비중만 말할 때만 허용하며, 그 외에는 N3을 씁니다.
- 흑백 인쇄 대비: 두 계열을 색으로만 구분하지 말고 직접 라벨을 붙입니다.

**차트 공통 규칙 보완 (신규 v2):** 0 기준선, 축 범위 표기, 이중축 조건, 음수 표시, 실적·추정 구분, 범주 순서. 세부는 `body-components.md` §3.

## 정보량 규칙

- **하한 글자 크기:** 본문 12pt, 표·각주 9pt를 지킬 수 없으면 장을 나누거나 별첨(D4)으로 보냅니다. 글자 크기를 하한 아래로 줄이지 않습니다.
- **근거 위치:** 수치가 있는 장표는 반드시 푸터 왼쪽에 출처·단위·기준일을 씁니다. 조건이 길면 BC-05 주석·출처 블록을 함께 씁니다.
- **강조 개수:** BLUE 강조는 장당 1~2곳 (BC-07 복수 패널에서 같은 시점을 반복 강조하는 것은 1곳으로 셉니다).
