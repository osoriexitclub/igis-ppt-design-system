# IGIS 제안서 디자인가이드-KAMCO v2

이지스자산운용의 **제안 발표용 PowerPoint와 A4 인쇄본** 전용 디자인 가이드입니다. 한국자산관리공사(KAMCO) 대상 제안 발표처럼 공기업 평가 환경을 기준으로 합니다. IGIS 디자인 시스템(IR·프레젠테이션 초안)을 복사해 만들었고, 웹 호환은 고려하지 않습니다.

- **매체:** PowerPoint 16:9 (33.87 × 19.05 cm). **발표 파일과 인쇄본은 같은 파일**입니다. 인쇄용 별도 판을 만들지 않으므로, 화면에서도 인쇄에서도 같게 보이는 요소만 씁니다.
- **밀도:** 공기업 제안서는 텍스트와 차트로 슬라이드를 채우는 편입니다. 여백보다 정보 배치를 우선하되, 단일 기준선과 위계로 정돈합니다.
- **상태:** v2. 컨설팅 보고서의 메시지 전달 방식과 데이터 표현 원칙을 **본문 장표에 한해** 도입했습니다. 변경 범위와 근거는 `CHANGELOG_v2.md`에 있습니다.
- **운영 원칙:** 서식과 IGIS 디자인 원칙은 고정하고, 본문 장표 유형만 인풋에 따라 늘립니다. 무엇을 고정하고 어떻게 늘리는지는 `change-policy.md`를 따릅니다.
- **문서 역할 (v2):**
  - 이 디자인시스템: 시각 구현 규칙 (`README.md`, `body-components.md`, `slide-types.md`)
  - 작성 지침 `IGIS_Deck_Authoring_Guide_v2.md`: 무엇을 어떻게 쓰고 어떤 구성요소를 고를지

## 하드 룰

1. **서체:** Pretendard만 씁니다. 위계는 굵기로만 표현합니다. Medium·SemiBold는 별도 글꼴 이름으로 고르고, 여기에 굵게(B)를 덧씌우지 않습니다.
2. **색:** 아래 팔레트 HEX만 씁니다. 제목·강조는 NAVY, 본문은 GRAY, 핵심 수치는 BLUE. 한 슬라이드 강조색은 1~2개, 나머지는 회색으로 배경화합니다.
3. **로고:** 밝은 배경에는 Positive(네이비), 네이비 배경에는 White. 비율 왜곡·회전·임의색·그림자·가림 금지.
4. **데이터:** 모든 차트·표에 **출처·단위·기준일**을 씁니다. 추정치 `(E)`, 예측 `(F)`. (v2: 정의·표본·환율 등 조건이 길면 `BC-05` 주석·출처 블록을 함께 씁니다.)
5. **배치:** 16:9, 좌우 안전영역 4.5%, 좌측 단일 기준선 정렬, 푸터 `{워드마크} _ {페이지}`.
6. **배경:** 네이비 풀배경은 **표지와 섹션 간지에만** 씁니다. 목차·본문·데이터·클로징은 반드시 흰 배경입니다.
7. **장식 선 금지:** 아이브로우 앞 대시, 제목 아래 짧은 포인트 라인 같은 장식용 가로선을 쓰지 않습니다. 선은 표·패널 헤더·KPI 행처럼 내용을 구분할 때만 씁니다.
8. **인쇄:** 정보는 흑백으로 인쇄해도 읽혀야 합니다. 색만으로 구분하지 말고 라벨·굵기·테두리를 함께 씁니다.
9. **인쇄 동일성:** 발표와 인쇄는 같은 파일이므로, 화면과 인쇄 결과가 달라질 수 있는 요소는 쓰지 않습니다.
   - 금지: 그림자, 반투명(투명도), 그라데이션, 광선·부드러운 가장자리·반사, 3차원 효과, `gray-200`보다 옅은 면, 0.75pt 미만 선, 9pt 미만 글자, Light 굵기
   - 겹친 색이 필요하면 미리 합성한 단색(`on-navy-*`)을 씁니다.

## 색

| 토큰 | 역할 | HEX |
|---|---|---|
| `navy` | 제목·강조, 표지·간지 풀배경(이 둘에만), 표 헤더 | `#2D375A` |
| `gray` | 본문 | `#5A5A5A` |
| `blue` | 포인트·핵심 수치, 차트 강조 1색 | `#0055A5` |
| `sky` | 네이비 위 라벨(표지·간지), 차트 보조 그래픽 (흰 배경 위 텍스트 금지) | `#78B9E6` |
| `white` / `black` | 배경 / 본문 대체 | `#FFFFFF` / `#000000` |

- **비율:** 화이트·뉴트럴 약 70%, 네이비 약 20%, 포인트(블루·스카이) 약 10%.
- **뉴트럴:** GRAY의 명도 변형만 씁니다 (`gray-900`·`500`·`400`·`300`·`200`). 선은 `gray-300` 이상, `gray-200`은 넓은 면 채움에만. 이보다 옅은 회색은 인쇄에서 사라질 수 있어 두지 않았습니다.
- **흑백 인쇄 주의:** NAVY와 BLUE는 흑백에서 명도 차이가 작고, SKY와 `gray-300`도 비슷해집니다. 두 색으로 의미를 구분해야 하면 값을 직접 라벨로 붙입니다.
- **투사 주의:** 흰 배경 위 SKY 텍스트는 대비가 약 2:1이라 프로젝터에서 보이지 않습니다.

## 시각 요소

- **배경:** 흰색과 네이비 풀배경(표지·간지)만. 그라데이션·패턴·질감·사진 오버레이 없음.
- **선과 모서리:** 각진 모서리. 블록을 여는 NAVY 1.25pt 룰, 구분은 `gray-300` 0.75pt. 장식용 가로선(아이브로우 대시, 포인트 라인)은 쓰지 않습니다. 장식 요소는 표준 본문의 BLUE 코너마크뿐입니다.
- **효과:** 그림자·투명도·그라데이션·광선·3차원 효과를 쓰지 않습니다. 구분은 단색 면과 선으로만 합니다. PowerPoint 도형 스타일 갤러리를 써도 효과가 붙지 않도록 테마에서 지웠습니다.
- **아이콘:** 지급된 아이콘 세트는 없습니다. 코너마크, A/B 번호 칩, 페이지 마커 같은 구조 요소로 대신합니다. 아이콘이 필요하면 선 굵기 1.5px 수준의 각진 라인 아이콘 한 세트만 씁니다.
- **로고:** `assets/Logos/`. 기본 로고(국문+영문), 워드마크, 시그니처 ①–④와 흰색판. 흰색판은 PNG 알파에서 추출한 래스터라 .ai 원본으로 교체가 필요합니다.
