# IGIS Asset Management — Design System Brief (for Claude Design)

> 이 브리프는 세 규격(design.md / visualization_standard.md / layout.md)을 토큰 우선으로 통합·정제한 것이다.
> **한 항목은 한 영역에서만 정의한다**: 색·폰트·로고 = design / 시각물 = viz / 배치 = layout.
> 아래 팔레트·서체·규칙을 **그대로** 적용하고, **팔레트 외 임의 색·임의 서체는 절대 금지**한다.

---

## 1. 색상 토큰 (역할 → HEX) — design.md 3장

| 토큰 | 역할 | HEX | 이름 |
|---|---|---|---|
| `ACCENT` | 제목·강조 헤드라인 | `#2D375A` | IGIS NAVY |
| `INK` | 본문 텍스트 | `#5A5A5A` | IGIS GRAY |
| `POINT` | 포인트·링크·핵심 수치 | `#0055A5` | IGIS BLUE |
| `HILITE` | 보조 그래픽·하이라이트 | `#78B9E6` | IGIS SKY |
| `BG` | 기본 배경 | `#FFFFFF` | PURE WHITE |
| `BG-FULL` | 표지·간지 풀배경 | `#2D375A` | IGIS NAVY |
| `REVERSE` | 어두운 배경 위 텍스트·로고 | `#FFFFFF` | PURE WHITE |
| `INK-STRONG` | 본문(대체) | `#000000` | PURE BLACK |

- **사용 비율**: 화이트·뉴트럴 ≈70% / 네이비 ≈20% / 포인트(블루·스카이) ≈10%.
- **강조 1색 원칙**: 한 슬라이드 강조색은 **1~2개 이내**. 나머지는 회색으로 배경화(gray-out).
- 헤어라인·gray-out 등은 **GRAY의 명도 변형만** 허용. 무지개 팔레트·형광색·녹/적 동시 사용 금지.

## 2. 타이포그래피 — design.md 4장

- **서체: Pretendard 단일 패밀리.** 위계는 **weight로만** 표현. 대체 서체: Malgun Gothic.
- 위계(16:9 기준):
  - 표지 타이틀 — Bold, 40–54pt — NAVY 또는 WHITE
  - 슬라이드 제목 — SemiBold, 28–32pt — `ACCENT`
  - 소제목 — Medium, 18–20pt — `ACCENT`/`INK`
  - 본문 — Regular, 14–16pt — `INK`
  - 캡션·출처 — Light, 9–11pt — `INK`
- 좌측 정렬 기본, 행간 1.3–1.5배. 강조는 색(`ACCENT`/`POINT`)·weight로. **밑줄·이탤릭 남용 금지.**

## 3. 로고 — design.md 2장

- 변형: 기본 로고(국문+영문) / 워드마크(IGIS) / 시그니처 ①–④.
- **밝은 배경 → Positive(네이비)**, **네이비·어두운 배경 → White(negative)**.
- 배경 명도(K값) 규칙: Full color **K0–30** / Black **K0–60** / White **K30–100**.
- 표지·간지 = White 로고(네이비 위). 본문 푸터 = 소형 워드마크.
- **금지**: 비율 왜곡·회전·임의색·그림자, 로고 일부 가림.

## 4. 캔버스 · 그리드 · 존 — layout.md 2·3장

- 비율 **16:9** (33.87 × 19.05 cm).
- **안전영역**: 좌우 4.5%(≈1.5cm), 상하 5%(≈0.95cm). 모든 텍스트는 **좌측 레일 단일 기준선**에 정렬.
- **12-컬럼 그리드**, 거터 0.3cm. 블록은 컬럼 라인에 스냅.
- **존**: 헤더 5–24%(Eyebrow → Title → Lead) / 콘텐츠 24–92% / 푸터 92–95%.
- **푸터**: 좌측 = 약어·`Source:`·단위/기준일, 우측 = 페이지 마커 **`{워드마크} _ {페이지}`**.
- **데이터/표 슬라이드는 출처·단위·기준일 필수.**
- 상용 분할: 6/6 · 5/7 · 4/8 · 3/9 · 12.

## 5. 슬라이드 아키타입 (7) — layout.md 7장

1. **표지** — `BG-FULL` + White 기본 로고 + 슬로건(우상) + 제목/날짜/부서.
2. **목차(TOC)** — 중앙-좌 로고 + 수평 룰 사이 번호 리스트.
3. **섹션 간지** — 네이비 풀배경 + 중앙 반투명 가로 밴드 + 섹션 번호·타이틀(White), SKY 포인트 라인.
4. **표준 본문** — 코너마크 + 헤더(Eyebrow/Title/Lead) + 콘텐츠 + 푸터.
5. **2-패널** — 좌/우 패널 헤더 베이스라인 일치, 분리는 여백 우선.
6. **데이터·표** — 전폭 또는 5/7. 출처·단위·기준일 필수.
7. **클로징** — 표지 골격 + 종결 문구 + Contact/면책.

## 6. 시각화 원칙 & 시그니처 양식 — visualization_standard.md

- **Message-Driven**: 슬라이드 제목은 명사구가 아닌 **결론 문장(Action Title)**. 한 슬라이드 한 메시지.
- **High Data-Ink**: 격자선·3D·그림자·불필요한 범례 제거.
- **색은 의미를 담을 때만**: 강조 1색, 나머지 gray-out.
- **출처·단위·기준일은 모든 데이터 시각물에 필수**. 추정치 `(E)`, 예측 `(F)`.
- 시그니처 4종: **폭포(Waterfall/Bridge) · 2×2 매트릭스 · 풋볼필드 · 민감도표**.
- 데이터 차트는 **편집 가능한 네이티브 차트** 우선. 다이어그램·표·플로우는 도형 기반.

## 7. Hard Rules (요약)

1. 서체는 **Pretendard만**, 위계는 weight로만.
2. 색은 **위 팔레트 HEX만**. 제목·강조=NAVY, 본문=GRAY, 포인트/핵심수치=BLUE. 강조 1~2색.
3. 로고는 배경 명도 규칙 준수, 밝은 배경=Positive / 어두운 배경=White. 왜곡·회전·임의색·그림자 금지.
4. 모든 데이터 시각물에 **출처·단위·기준일**.
5. 16:9 · 안전영역(좌우 4.5%/상하 5%) · 좌측 정렬 · 푸터 `{워드마크} _ {페이지}`.
